# Connect4
A simple Connect 4 game, starting from a Python version created as part of "Build Connect Four Using Python" Codecademy course. The game has been recreated in JavaScript to run in a console using Node as well, and this version adapted later for use with HTML and CSS to make a more visually appealing webpage version. A single player version against a randomly pacing opponent has been added alongside the original two player game, with buttons to select between versions. The single player version also serves as a placeholder for a more complex computer opponent following further study on Machine Learning.


## Skills

This project serves as a simple practice on coding basics, building up as I learn new skills:

* Recalling basic Python and JavaScript syntax (conditionals, loops, functions etc) for use in command line programs.
* Git version organisation and GitHub use.
* Simple HTML, CSS, and JavaScript practice for page setup, styling and interactivity.
* Generating and altering HTML elements with JavaScript to produce an interactive game.
* Basic HTML form use for selecting user options.
